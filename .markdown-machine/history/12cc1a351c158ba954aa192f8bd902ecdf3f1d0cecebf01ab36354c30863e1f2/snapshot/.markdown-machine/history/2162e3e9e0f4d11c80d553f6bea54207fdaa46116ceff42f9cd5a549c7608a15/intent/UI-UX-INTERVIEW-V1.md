# Manna Version 1 UI/UX interview baseline

The human approved the complete UI/UX requirements interview recorded in `docs/01-spec/manna-v1-ui-ux-requirements.md`.

The accepted direction opens directly to a quiet Reader; uses Read, Search, Study, Notes, and Library as primary destinations; progressively discloses complexity; keeps one active resource per category by default; supports intentional unlimited comparison sets; allows every substantive pane to expand to full screen and return to the exact prior context; unifies Search and Verse Finder; guides safe local imports; and makes accessibility, local ownership, recovery, and responsive parity mandatory.

Selecting a place recenters an Atlas already present in Study and offers `Open in Atlas` only when Atlas is absent. User-facing study exports prioritize PDF, DOCX, and plain text.

This baseline authorizes the next agent to design and verify flows and appearance. It does not approve any mock, declare Product Freeze, recompile the roadmap, or authorize application implementation.
