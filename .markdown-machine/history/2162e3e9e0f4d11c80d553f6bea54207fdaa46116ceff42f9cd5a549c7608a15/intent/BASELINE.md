# Manna accepted baseline

Manna is a comic-book-themed, offline-first Bible study workstation delivered as one self-contained HTML file for desktop, tablet, and phone. Its non-negotiables include a single release file, offline core behavior, no server runtime, Scripture integrity, local user ownership, safe untrusted imports, and deterministic study tools. The existing specifications and implementation history are the authoritative project baseline for product behavior; this reconciliation does not reinterpret them.
