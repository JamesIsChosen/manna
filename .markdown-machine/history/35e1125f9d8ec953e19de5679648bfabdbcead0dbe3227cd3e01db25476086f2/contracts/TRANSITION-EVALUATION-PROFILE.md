# Transition Evaluation Profile

This is the closed deterministic operator vocabulary for ordinary `AuthorityTransition` admission.

`TRANSITION-ADMISSION/v2` may invoke only operator IDs in this profile, using structured `{ "op": ..., "args": ... }` objects. Unknown operators, missing arguments, extra arguments, or free-form instruction strings are invalid.

The structural rule is constitutional: ordinary transitions have exactly one predecessor, preserve its epoch, and increment its sequence by exactly one. `AUTHORITY_FORK_RESOLVE` alone is multi-parent; it starts `max(parent epoch)+1` at sequence `0`.

`KERNEL_MIGRATE` remains an ordinary single-parent authority transition. A current machine that already supports coherent cutover may perform the atomic binding replacement directly. For a legacy current machine whose exact `KERNEL_MIGRATE` can admit only a manifest, the migration procedure must first prove bridge-safe old/current state; active STOP or another barrier whose lawful authority-transition recovery would be stranded blocks bridge entry. Only then may the old contract admit the exact candidate manifest as a compatibility bridge. The resulting singleton is `MIGRATION_BRIDGE_CURRENT` precisely when current `KERNEL_MANIFEST.distribution_origin_ref` differs from the current `DISTRIBUTION_ORIGIN` binding. Candidate semantics are then current because the old contract admitted the manifest, but substantive transitions are denied; only the candidate `KERNEL_MIGRATE` finalizer may establish the coherent candidate origin/binding set. File presence or candidate prose never establishes the bridge.
