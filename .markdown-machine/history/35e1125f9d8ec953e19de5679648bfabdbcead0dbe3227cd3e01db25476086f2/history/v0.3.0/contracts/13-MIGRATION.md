# Migration

Projects pin exact kernel origin/version/content identity and exact capability definition versions.

There is no silent auto-sync.

Migration advisories may be:

- `OPTIONAL`
- `RECOMMENDED`
- `REQUIRED_BEFORE_SPECIFIC_OPERATION`
- `UNSUPPORTED_REVIEW_REQUIRED`

Migration is a governed candidate/publication transition. It may update future governance mechanics but never rewrites original HumanStatements, historical authority transitions, historical reviews, old effects, or prior accepted product freezes.
