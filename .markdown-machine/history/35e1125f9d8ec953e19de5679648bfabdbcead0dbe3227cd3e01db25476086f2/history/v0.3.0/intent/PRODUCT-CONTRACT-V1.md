# Manna Version 1 intent baseline

The accepted human product interview reopens Manna as a new-product discovery effort while preserving repository answers as evidence. The canonical current contract is `docs/01-spec/manna-v1-product-contract.md`.

Current intent establishes a clean Reader by default, on-demand deep Study Desk, KJV PCE baseline, verified exhaustive Strong's behavior, selectable commentary/resources, unlimited deliberate comparison sets, local intelligent import, consumed module/document storage, confidence-tiered semantic relationships without mandatory line-by-line review, interactive Map Packs, full-library backup, staged releases, and a permanent physical-Bible verification reminder.

The existing P0.1 prototype is evidence and a visual reference, not current Product Freeze. The UI/UX interview is now canonical in `docs/01-spec/manna-v1-ui-ux-requirements.md` and `intent/UI-UX-INTERVIEW-V1.md`. Application implementation remains stopped until design verification and explicit Product Freeze.
