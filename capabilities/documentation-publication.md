# Documentation / Publication

## Interview focus

Audience, purpose, required factual authority, confidentiality, publication destination, editorial posture, legal/rights constraints, approval/publication boundary.

## Lifecycle fragment

```text
Intent
 -> Source/currentness recovery
 -> Outline/structure
 -> Draft
 -> factual/editorial review
 -> approval boundary
 -> publication readiness
 -> publication effect if explicitly authorized
```
