# IT / Systems Operations

## Interview focus

Operational outcome, asset/service scope, acceptable downtime, maintenance/change windows, recovery expectations, credentials/ownership boundaries, external dependencies, and human-reserved effects.

## Lifecycle fragment

```text
Intent
 -> Asset/current-state validation
 -> Desired operational state
 -> Change plan
 -> Risk/impact review
 -> Controlled change
 -> Verification
 -> Recovery/operational closeout
```
