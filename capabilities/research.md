# Research

## Interview focus

Question, intended decision/output, scope, methodology constraints, source/evidence standards, reproducibility, uncertainty tolerance, publication boundary, and run horizon.

## Lifecycle fragment

```text
Intent
 -> Research question
 -> Method/protocol
 -> Evidence collection
 -> Analysis
 -> Methodological review
 -> Conclusion
 -> Publication boundary
```

Research evidence never becomes positive project authority merely because it is persuasive.
