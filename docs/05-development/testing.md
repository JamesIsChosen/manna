# Testing

## Layers

| Layer | Proves | Runs |
|---|---|---|
| Unit | A function does what it claims | every commit |
| Integration | Components agree on their contracts | every commit |
| Golden | Output matches a known-correct fixture | every commit |
| Failure | Bad input fails **closed**, non-zero | every commit |
| Manual | What automation cannot reach | before release |

## Independent test data

Fixtures generated by the implementation being tested prove nothing -- they are
circular. Test data must come from an independent source: the upstream
specification, a reference implementation, or a second tool.

Record the provenance of every fixture in `fixtures/README.md`: where it came
from, its version, and its checksum.

## Negative tests are not optional

For anything that validates, parses, or imports:

- empty input
- maximum-size input
- malformed input
- input that is valid but wrong
- input crafted to be hostile

Each must fail **closed** with a non-zero exit and a clear message.
