# Kernel Constitution

The universal kernel is capability-neutral. It owns:

- positive authority/currentness;
- bootstrap trust;
- human intent provenance;
- Task/Attempt identity;
- capability onboarding framework;
- LifecycleGraph revisions;
- Run Horizon;
- Inbox/change control;
- convergence;
- context routing/representation;
- skills routing;
- Worker/review independence;
- enforcement requirements;
- resources/effects;
- external currentness;
- STOP/recovery;
- handoff projections;
- kernel/capability migration.

Capability definitions may tighten these rules but may never weaken them.

Software Product Freeze is capability-specific, not universal.
