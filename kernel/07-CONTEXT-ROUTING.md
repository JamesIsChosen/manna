# Context Routing

**Context is routed, not accumulated.**

Exhaustive project governance does not imply exhaustive context delivery.

## Delivery classes

- `MANDATORY_NOW`
- `AVAILABLE_ON_DEMAND`
- `EXCLUDED`

## Fidelity classes

- `EXACT`
- `LOSSLESS_STRUCTURAL`
- `REVERSIBLE_PROJECTION`
- `DERIVED_EXPLORATORY`

Routing class and fidelity are independent.

Mandatory authority, exact human decisions, ROE, prohibitions, STOP state, unresolved effects, and exact immutable review subjects where required must not be summarized away.

Model-generated compression defaults to `DERIVED_EXPLORATORY` and cannot satisfy a mandatory governing floor without an accepted semantic representation contract.

## Progressive disclosure

Start with:

1. current authority floor;
2. exact Task/OperationContract;
3. exact relevant intent/capability/lifecycle state;
4. exact required security/effect constraints;
5. selected skills.

Expand only for a concrete criterion, contradiction, dependency, or hypothesis.

## Representation provenance

Any governing representation binds source identity/digest, Task, semantic surface, transform identity/version, fidelity class, exact-original locator, currentness, and exposure domain.

Failure moves toward higher fidelity or BLOCK. Never compress harder to escape a semantic failure.
