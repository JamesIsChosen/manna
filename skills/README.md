# Skills

This project does not copy a large generic skill library into every Worker context.

The Skill Router selects procedures by capability, Task purpose, lifecycle/review purpose, criticality, evidence requirement, and Worker/harness capability.

External skill libraries must be pinned/audited according to project policy before governing use.

Skills remain procedures, never project authority.
